# Discogs Deal Shark 1.4.0

Deal Watcher has grown teeth. This release introduces the new **Discogs Deal Shark** name and the
shark-biting-a-diamond identity across the desktop app, shortcuts, installers and GitHub project.

## What's new

- **Complete Deal Shark rebrand:** new dashboard logo, application icon, release thumbnail, window
  title, notifications and documentation.
- **Upgrade-safe:** the existing application identity is retained and legacy Deal Watcher settings,
  credentials, scan history and configured GitHub repositories continue to be recognized.
- **New installer names:** Windows and macOS packages now use the Discogs Deal Shark brand.
- **Existing features preserved:** Deals, rare-restock alerts, price history, Scout discovery,
  sold-median publishing and optional cloud alerts work as before.

## Downloads

- Windows x64: `Discogs-Deal-Shark-Setup-1.4.0.exe`
- macOS universal (Intel + Apple Silicon): `Discogs-Deal-Shark-1.4.0-mac.dmg`
- `SHA256SUMS.txt` contains the checksums generated by the release workflow.

## Signing notice

These installers are currently unsigned. Windows may show a SmartScreen warning. macOS requires a
one-time Gatekeeper override. Follow the exact steps in `INSTALL.md`. The app never buys records;
Scout changes your Discogs wantlist only after you press **Add to wantlist**.
