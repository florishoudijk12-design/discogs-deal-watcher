# Discogs Deal Watcher 1.3.0

This release makes the desktop app a faster daily review tool and adds discovery beyond your
existing wantlist.

## What's new

- **Scout:** search Discogs by style or genre for records outside your wantlist, filter on an
  estimated VG+ value, and add a promising release to your wantlist with an explicit click.
- **Price-drop and relist history:** see when the same listing gets cheaper or returns to the market.
- **Daily deal review:** redesigned Deals and Rare gems views with clearer explanations and actions.
- **New branding:** refreshed in-app logo, desktop icon and release thumbnail.
- **More reliable sold medians:** clearer GitHub push status and retry handling.

## Downloads

- Windows x64: `Discogs-Deal-Watcher-Setup-1.3.0.exe`
- macOS universal (Intel + Apple Silicon): `Discogs-Deal-Watcher-1.3.0-mac.dmg`
- `SHA256SUMS.txt` contains the checksums generated by the release workflow.

## Signing notice

These installers are currently unsigned. Windows may show a SmartScreen warning. macOS requires a
one-time Gatekeeper override. Follow the exact steps in `INSTALL.md`. The app never buys records;
Scout changes your Discogs wantlist only after you press **Add to wantlist**.
